# Cardápio Digital

Projeto acadêmico desenvolvido na disciplina de **Desenvolvimento Web**, com o objetivo de construir um cardápio digital moderno, responsivo e interativo.

Além de aplicar os conteúdos estudados durante o semestre, este repositório registra minha evolução prática na área de **Sistemas e Desenvolvimento Web**, servindo também como parte do meu portfólio profissional.

## Sobre o projeto

O **Cardápio Digital** será desenvolvido de forma incremental ao longo da disciplina. Cada etapa adicionará novos conhecimentos e funcionalidades, começando pela estrutura da página e avançando até a criação de interações com JavaScript.

Nesta primeira fase, o projeto utiliza as três tecnologias fundamentais da Web:

- **HTML:** estrutura e organização do conteúdo.
- **CSS:** estilização, layout e identidade visual.
- **JavaScript:** interatividade e comportamento dinâmico.

## Objetivos de aprendizagem

Durante o desenvolvimento do projeto, serão explorados os seguintes conceitos:

- Funcionamento da Web e da arquitetura cliente-servidor;
- Comunicação entre navegador, servidor e banco de dados;
- Funcionamento dos protocolos HTTP e HTTPS;
- Fluxo de uma requisição até a exibição da página;
- Estruturação semântica de páginas com HTML;
- Estilização e criação de layouts com CSS;
- Desenvolvimento de interações com JavaScript;
- Responsividade para celulares, tablets e computadores;
- Organização do código em componentes reutilizáveis;
- Versionamento de código com Git e GitHub;
- Inspeção, testes e depuração no navegador.

## Etapas do desenvolvimento

| Etapa | Tema | Objetivo |
|---|---|---|
| 01 | HTML | Construir a estrutura e adicionar títulos, textos, imagens, listas e informações do cardápio. |
| 02 | CSS | Aplicar cores, tipografia, espaçamentos, posicionamento e identidade visual. |
| 03 | Componentes | Organizar a página em partes reutilizáveis para facilitar a manutenção e a evolução do projeto. |
| 04 | Responsividade | Adaptar a interface para celulares, tablets e computadores. |
| 05 | JavaScript | Adicionar ações, eventos e interações para tornar o cardápio dinâmico e funcional. |

## Funcionalidades planejadas

- Exibição dos itens do cardápio por categorias;
- Apresentação de nome, descrição, imagem e preço dos produtos;
- Interface adaptável a diferentes tamanhos de tela;
- Navegação simples e intuitiva;
- Interações desenvolvidas com JavaScript;
- Componentes organizados e reutilizáveis.

> As funcionalidades serão adicionadas gradualmente conforme o avanço da disciplina.

## 🇺🇸 English

# Digital Menu

Academic project developed for the **Web Development** course, with the goal of building a modern, responsive, and interactive digital menu.

In addition to applying the concepts studied throughout the semester, this repository documents my practical growth in **Systems and Web Development** and serves as part of my professional portfolio.

## About the Project

The **Digital Menu** will be developed incrementally throughout the course. Each stage will introduce new knowledge and features, starting with the page structure and progressing toward interactive features built with JavaScript.

In this first phase, the project uses the three core web technologies:

- **HTML:** content structure and organization.
- **CSS:** styling, layout, and visual identity.
- **JavaScript:** interactivity and dynamic behavior.

## Learning Objectives

The following concepts will be explored during the development of the project:

- How the Web and client-server architecture work;
- Communication between the browser, server, and database;
- How the HTTP and HTTPS protocols work;
- The flow of a request until a page is displayed to the user;
- Semantic page structure with HTML;
- Styling and layout development with CSS;
- Interactive features with JavaScript;
- Responsive design for mobile phones, tablets, and computers;
- Code organization using reusable components;
- Version control with Git and GitHub;
- Browser inspection, testing, and debugging.

## Development Stages

| Stage | Topic | Goal |
|---|---|---|
| 01 | HTML | Build the structure and add headings, text, images, lists, and menu information. |
| 02 | CSS | Apply colors, typography, spacing, positioning, and visual identity. |
| 03 | Components | Organize the page into reusable parts to make maintenance and future development easier. |
| 04 | Responsive Design | Adapt the interface for mobile phones, tablets, and computers. |
| 05 | JavaScript | Add actions, events, and interactions to make the menu dynamic and functional. |

## Planned Features

- Display menu items by category;
- Show each product's name, description, image, and price;
- Provide an interface that adapts to different screen sizes;
- Offer simple and intuitive navigation;
- Add interactions using JavaScript;
- Organize the interface into reusable components.

> Features will be added gradually as the course progresses.
